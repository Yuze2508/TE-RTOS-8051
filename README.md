# TE_8R_8051 — 8051 实时操作系统

> 面向 8051 内核全系列单片机的极简抢占式 RTOS

## 简介

TE_8R_8051 是一个为 8051 内核量身打造的实时操作系统，在 RAM 仅有 256 字节 data + 256 字节 idata 的严苛约束下，实现了完整的抢占式调度、邮箱通信、互斥量与优先级继承、软件定时器等机制。

### 核心特性

| 特性 | 说明 |
|------|------|
| 抢占式优先级调度 | 16 级优先级（0~15），饥饿老化自动提升低优先级任务，硬实时档（10~15）不受老化侵入 |
| 工作区模式 | 每个任务拥有独立 idata 工作区 + xdata 栈区，冻结帧存 xdata，idata 栈需求极小 |
| TCB 冷热分离 | 热字段放 data（每 Tick 高频访问），冷字段放 xdata，RAM 零增长 |
| 三层栈溢出检测 | L1 边界检查 + L2 金丝校验 + Tick 哨兵抽检，溢出自动停机并输出 6 项诊断信息 |
| 邮箱（最新值有效） | 非队列语义，旧信覆盖，ISR 可安全投递（Post），任务间可唤醒投递（Send） |
| 互斥量 + 优先级继承 | 自适应等待位图（打破 8 任务硬限），继承基于静态优先级，自锁检测 |
| 软件定时器 | 标志位语义（非回调），零漂移保证，到期未读不再减 1 |
| 配置分离 | 用户只改 `TE_8R_8051_config.h` 一个文件，汇编侧 `config.inc` 手动同步 |
| 汇编-C 契约 | 编译时断言保证跨语言结构体大小/常量一致性 |
| 谓词宏 | 任务状态判断用命名谓词，消灭魔数 |

### 资源开销（4 任务典型配置）

| 存储区 | 对象 | 大小 |
|--------|------|------|
| data | `tcb_hot[5]`（含空闲任务） | 25 字节 |
| xdata | `tcb_cold[4]` | 12 字节 |
| idata | 各任务工作区（运行时仅当前任务占用） | 按栈大小配置 |
| code | 内核合计 | ~1.5 KB |

### 最小栈预算

```
stack_size ≥ 33 (初始帧15 + 中断帧17 + 哨兵1) + 2 × 最大调用嵌套深度
```

## 快速上手

```c
#include "TE_8R_8051.h"

unsigned char xdata stack_task0[42];
unsigned char xdata stack_task1[42];

void task0(void) large { while (1) { /* ... */ TE_8R_8051_Delay(10); } }
void task1(void) large { while (1) { /* ... */ TE_8R_8051_Delay(20); } }

void main(void)
{
    硬件初始化();
    TE_8R_8051_Init();
    TE_8R_8051_Task_Create(0, 5, task0, stack_task0, sizeof(stack_task0));
    TE_8R_8051_Task_Create(1, 8, task1, stack_task1, sizeof(stack_task1));
    TE_8R_8051_Start();
    while (1);
}
```

## 适用芯片

适用于所有基于 **8051 内核**的单片机，包括但不限于：

- 传统 8051（12T 模式）：AT89C51、AT89S52 等
- 增强型 1T 8051：STC15 系列（如 STC15F2K60S2）、STC8 系列、STC32G 系列等

**适配说明**：

- 1T 模式芯片需在 `TE_8R_8051_Init()` 中设置 `AUXR |= 0x80` 开启 1T 加速（已内置）
- 12T 模式芯片无需额外配置，定时器重装载值由 `FOSC`、`TICK_MS` 宏自动计算
- 定时器 0 已被内核占用为系统心跳源，用户可使用定时器 1 / 定时器 2
